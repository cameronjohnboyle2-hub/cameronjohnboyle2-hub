# Cluck & Squeak · Browser simulator

Chickens and mice battle on a 2D map with obstacles, roads, resources, and reinforcements. This folder contains the standalone Canvas version and its JavaScript simulation engine.

Run `python -m http.server 8080` from this folder and open http://localhost:8080. Use a local server because the browser loads JavaScript modules.

See the [portfolio write-up](../../docs/CLUCK_AND_SQUEAK.md) for the FigJam version and its classroom mode.
